## 后端热重启
- 给后端加了 nodemon 热重载。新增 `server:watch` 脚本(`nodemon --watch server --ext js,json --ignore server/data --ignore server/node_modules server/index.js`),`dev:all` 中的 `server` 改为 `server:watch`。
- `--ignore server/data` 避免持久化 JSON 频繁写入导致死循环重启。改后端文件后自动重启,无需手动。nodemon 已加入 devDependencies(`^3.1.14`)。

## 会话归档过滤接口
- `GET /api/sessions` 新增 `archived` 查询参数:空/缺省=全部,`'0'`=未归档,`'1'`=已归档。session 模型已有 `archived` 布尔字段(软删除,数据保留在 sessions.json)。
- 前端 `fetchSessions(archived)` 支持该参数;`App.vue` 与 `ChatPanel.vue` 初始化时调用 `fetchSessions(0)`,左侧对话框仅显示未归档会话。

## 编辑规范
- 绝对不要对 `.vue` SFC 使用 `write_to_file` 整段覆盖——会把 `<template>`/`<style>`/import 全部丢掉,Vite 会报 `At least one <template> or <script> is required`。`src/sessions.js` 这类纯 JS 模块用 `write_to_file` 是安全的。
- 修改 SFC 时只用 `replace_in_file` 精准改;如已误覆盖,用 `git checkout -- <file>` 恢复后再改。

- 用户决定维持 A：无项目=纯聊天/MCP，不能操作本地文件（chat.js:61 `projectRoot ? perm : 'none'` 不变，不做 B 沙箱目录）。

## 回退功能（对话回退 + 文件回退）已落地
- 对话回退 rollbackTo：MessageList user 气泡底部 ↶ 图标 emit('rollback')；ChatPanel 截断该 user 消息及之后 + 确认弹窗 + 原文回填输入框。regenerate（assistant 气泡底部 📋复制↻重做）保留前文重生成。

- 关键 bug 修复：
